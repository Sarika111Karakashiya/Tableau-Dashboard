This project presents an interactive Zomato Restaurants Analysis Dashboard that provides insights into restaurant performance, revenue trends, customer ratings, and geographic distribution.
The dashboard helps stakeholders understand business performance across years, cities, countries, and time periods (weekday vs weekend).
**Objectives**
Analyze revenue trends over time
Compare weekday vs weekend performance
Identify top-performing restaurants and cities
Understand country-wise and city-wise restaurant distribution
Track monthly and yearly revenue patterns.
